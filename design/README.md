# Alternativas de diseño

Abre `ux-alternatives.html` en un navegador. Es un archivo autónomo: no necesita instalación ni conexión a internet.

Puedes comparar cuatro estilos (Esencial, Calma, Perspectiva y A una mano), alternar entre el inicio y el formulario, cambiar el tema y probar el selector gasto/ingreso/traspaso. Todos los datos son de ejemplo y no se envían a Firefly III.

El diseño definitivo está pendiente de elección. Se pueden combinar elementos de varias propuestas.
